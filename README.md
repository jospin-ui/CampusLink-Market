## 3. Problem Statement
University students frequently need affordable textbooks, electronics, furniture, calculators, lab equipment, and other campus essentials. However, these transactions are currently conducted through informal, cluttered channels such as WhatsApp groups, Telegram channels, or physical bulletin boards. 

These informal methods make it incredibly difficult to find specific items, verify seller authenticity, compare prices, or arrange safe meetups. CampusLink Market addresses these challenges by providing a centralized, secure e-commerce marketplace exclusive to verified university students, ensuring a trusted environment for peer-to-peer campus commerce.

## 5. User Flow Explanation
The application layout follows a logical, frictionless sequential path designed for a busy student:

1. **Splash Screen / Welcome:** Introduces the platform branding.
2. **Authentication:** The user logs in or registers securely using their official university email address.
3. **Marketplace Dashboard (Home):** Displays a global search bar, categorized item browsing shortcuts, and a grid of personalized "Recent Listings".
4. **Search / Filter Action:** The user filters listings by selecting a specific category (e.g., "Academic Supplies").
5. **Product Details Page:** Displays item photos, condition description, pricing, and the seller’s limited public profile.
6. **In-App Communication (Chat):** Opens a secure internal chat window allowing the buyer and seller to safely text and negotiate a physical meetup location on campus.
7. **Checkout / Reserve:** Confirms the item reservation so the seller can take down the listing.

## 6. Features Implemented (Version 1)
* **Secure Student Authentication:** Email validation locked exclusively to college domain extensions.
* **Smart Marketplace Browsing:** Search, filtering, and 10 custom student-centric categories (Books, Electronics, Hostel Essentials, Free & Exchange, etc.).
* **P2P Listing Management:** An easy-to-use form for student sellers to upload photos, set prices, write descriptions, and manage live listings.
* **Secure In-App Chat:** Real-time messaging that keeps personal phone numbers private until a trusted meetup is established.
* **Student Profile Dashboard:** Tracks active items for sale, saved favorites, and a history of completed marketplace purchases.

---

## 7. Design Explanation
* **Visual Hierarchy:** Clean, modern, card-based interface structure layout. High-priority elements like item prices and search bars use strategic sizing to catch the user's attention instantly.
* **Typography:** Clean, legible sans-serif typography suitable for fast mobile reading. Bold weights are reserved strictly for navigation headers and numeric price callouts.
* **Color Palette:** A corporate, trust-inducing primary color (e.g., deep campus blue) paired with an energetic accent color (e.g., vibrant orange or green) for call-to-action buttons like "Chat with Seller".

---

## 8. Accessibility Considerations (UI/UX Best Practices)
* **High Color Contrast:** All text and button layouts comply with WCAG AA accessibility contrast ratios to ensure maximum readability in outdoor sunlight.
* **Large Touch Targets:** Buttons and interactive icons are sized to a minimum of 44x44 pixels to ensure comfortable tapping on mobile viewports.
* **Clear Input Labels:** Text fields feature persistent, highly visible labeling alongside placeholder text so users never lose context when filling forms.
